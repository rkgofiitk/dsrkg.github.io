# Data Structure Using Python

This repository is for programs learning Data Structure. Though an AI code assistant has made coding easy. Learning to write and understand
Data Structures and Programming remain important aspects of training in Computer Science. The coding assistant will not teach you
how to program, but will generate code when you ask correct questions. If questions are not precise, the coding assistants, like any other
programmer, end up generating useless code. Apart from the issue of preciseness of prompting, AI coding assistant may sometimes offer
explanations without much clarity. Data Structure is one of the core subjects of the computer science course. It deals with the organization of
data so that the performance of programs is not affected by the storing and retrieving of data. Visualize a large warehouse of a 
logistics movement company. If the warehouse is not properly organized or the objects are not stored in an orderly manner, the movement of goods is affected.
Similarly, if the data objects with linear relationships are mixed up with data objects with nonlinear relationships, then the latency of
both retrieval and storing for any specific data object becomes long. So, the performance of a program becomes an issue. Therefore,
learning and understanding Data Structure is very critical. Programming is not essential to understanding the principles behind the 
structuring of data. However, the role algorithm is crucial because it determines both complexity and performance. In this repository,
we intend to focus on these aspects and provide tkinter GUI-based Python programs for important Data Structures.

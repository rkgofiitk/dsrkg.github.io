## Read Me

The folder contains files for Flask animation of stack operations. There aree three files:
- <b>stackOps.py</b>: contains class file for basic stack operations
- <b>stk_v4.py</b>: contains routes for Flask app invoked for displaying the stack and operations on it.
- <b>index.html</b>: contains the frontend function to control the visual display of operation with animation.

## Animation of Trees

The directory contains animation programs for:
- Binary trees
- Binary search trees

A binary tree is the simplest nonlinear data structure that is a collection of objects called nodes. A node maintains three atomic items of information, namely
- Node data
- Pointer to left child
- Pointer to right child

Using the pointers, a node can hold a collection of data in a structured manner, allowing a walk in either of the two directions, left or right. Each pointer takes us to a node object. So a node is a self-referential object. A walk along a collection of nodes can yield a large number (a power of 2) of paths, where each path terminates at a node with both pointers null. We can view each path as a linear list. So in simple terms, a binary tree may constitute a collection of up to a power of 2 linear lists. 

A binary search tree (BST) is a binary tree in which a node's left and right pointers define a partial ordering of the information stored along each path in the tree.
